# Your profile (template)

Copy this folder to `profile/` (git-ignored) and replace every value with your own.

| File | What it is |
|---|---|
| `fact_bank.json` | The only source of resume content: contact line, roles, **fact bullets with ids**, projects, skills, education. Write only things you actually did. |
| `presets.json` | Standing answers: name, contact, location, work authorization, sponsorship, EEO choice, school/GPA/grad year, current employer and title. Legal answers are never generated by the engine. |
| `lanes.json` | Your domains. Each lane is a resume variant (headline, summary, which fact ids, in which order) plus routing rules that send a job to a lane. |
| `domains.json` | Discovery filters: which titles and locations count as "your domain". |
